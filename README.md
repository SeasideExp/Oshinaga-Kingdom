# お品書キングダム～沢山同人誌を並べます！ (Ver.0.70f)

> **最終更新: 2026年11月13日 ／ 最新バージョン: Ver.0.70f**  
> ※ 各バージョンの詳細な更新履歴は [**`CHANGELOG.md`**](./CHANGELOG.md) をご覧ください。

同人誌即売会向けの**SNS告知用・印刷用お品書き画像**、会場卓上用の**簡易お品書き**、および当日の在庫管理・会計を支援する**当日頒布物帳票**を一括作成・自動レイアウトできるWebツールです。

---

## 📖 1. 概要

既刊・新刊・グッズを登録するだけで、見栄えの良いお品書き画像を自動グリッド配置で生成できます。  
さらに、同一データから卓上用の簡易お品書きや在庫管理帳票までワンクリックで連動出力可能です。

---

## ✨ 2. 主な機能

- **頒布物管理 ＆ 自動グリッドレイアウト**
  - 書名・発行年月・コメント・頒価・書影・ジャンルを一元管理し、点数に応じた最適な列数で自動配置します。
  - アイテムごとのサイズ強調、空白枠（スペーサー）挿入、ドラッグ＆ドロップ並び替え、Undo/Redo に対応しています。
- **ラベル ＆ 売り文句POP**
  - メイン／サブラベル（各種バッジ形状・配色カスタマイズ）や、吹き出し・透過画像を使ったPOPを自由に配置できます。
- **デザイン ＆ フォント設定**
  - テーマプリセット、背景画像・グラデーション設定、色覚多様性（CUD）に配慮した推奨配色への切り替えに対応しています。
  - PCフォントの検出・登録に加え、手持ちフォントファイル（`.ttf` / `.otf` / `.woff` / `.woff2`）の追加にも対応しています。
- **3種類の出力**
  - **お品書き画像**: SNS向け・印刷向け解像度での PNG / PDF 出力、印刷プレビューに対応。
  - **簡易お品書き**: 卓上用の小型版（A6/B6）を PNG / 複数ページ PDF で出力。端数価格の強調表示や独立ソートにも対応。
  - **当日頒布物帳票**: 1日／2日連続開催対応のA4白黒在庫・売上管理シートを1ページに自動収容して出力。
- **データ保存 ＆ バックアップ**
  - ブラウザ内に作業内容を自動保存するほか、画像・フォント込みの CSV 保存／読込やローカルフォルダへの一括保存に対応しています。

> [!WARNING]
> **データのバックアップについて**: 作業データはブラウザ内ストレージに自動保存されますが、閲覧データの消去やシークレットウィンドウの終了により失われる恐れがあります。こまめに **「💾 CSV保存」** または **「📁 フォルダへ保存」** でローカルへ保存することを推奨します。

## 🚀 3. 動作方法

Webサーバーの構築は不要です。**[`index.html`](./index.html) をWebブラウザ（Chrome / Edge / Safari 等）で直接開くだけ（`file://`）**で、オフライン環境でもそのまま動作します。
